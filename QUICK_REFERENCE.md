## 🔧 PAYMENT GATEWAY SETUP

### iPay88 (Recommended) ⭐
```
1. Sign up: https://ipay88.com
2. Get: Merchant Code (M12345) + Secret Key
3. Add to Railway Variables
4. Uncomment iPay88 code in server.js
5. Test!

Cost: 2% per transaction
Methods: Credit cards, bank transfer, ewallet
```

### Stripe (International)
```
1. Sign up: https://stripe.com
2. Get: Secret & Public keys
3. Add to Railway Variables
4. Uncomment Stripe code in server.js
5. Test!

Cost: 2.9% + $0.30
Methods: Credit cards mostly
```

## COMMON QUESTIONS

**Q: How much can I make?**
A: RM 150,000+ per boat per year. With 5 boats: RM 750,000+/year potential.

**Q: Is payment integration hard?**
A: No. iPay88 setup = 15 minutes. Follow the comments in server.js.

**Q: How do I get customers?**
A: Social media + Google Ads + hotel partnerships. Focus on reviews.

**Q: What if someone doesn't pay?**
A: Payment gateway charges their card. If they have no card, require prepayment.

**Q: Should I do discounts?**
A: Start with 10% for early customers to build reviews. Then raise prices.

**Q: How do I handle bad weather?**
A: Policy: Offer full refund or reschedule. Communicate 24 hours before.

**Q: What insurance do I need?**
A: Boat insurance (liability, damage) + public liability insurance.
